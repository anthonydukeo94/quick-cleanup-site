# Quick Cleanup public information site

This is a separate replacement-site draft for the intended $25 Quick Cleanup offer. It does not modify or delete the existing ChatGPT-hosted site or the Jarvis Core repository.

## Current safeguards
- States orders are closed.
- No checkout button, payment URL, file upload or order form.
- Planned scope is one CSV file and up to 500 data rows. XLSX is explicitly excluded from this offer page until supported and validated.
- No customer information is collected by the site.

## Publish checklist
- Review this copy and identity/contact details.
- Confirm the secure intake, retention, payment reconciliation and delivery path before taking orders.
- Do not add PayPal checkout or customer uploads until the end-to-end workflow is proven.
